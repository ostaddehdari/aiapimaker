# Stage 05 — معیارهای پذیرش رابط React

| شناسه کار | خروجی قابل بررسی |
|---|---|
| W05.01 | Vite 8، React 19، TypeScript، مسیر `VITE_BASE_PATH` |
| W05.02 | صفحات `login/admin/app`، React Router و مسیرهای داخلی |
| W05.03 | `dir=rtl` و Vazirmatn بسته‌بندی‌شده محلی |
| W05.04 | Font Awesome با واردسازی مجزای آیکون‌ها |
| W05.05 | متغیرهای CSS، تم روشن/تاریک با دکمه واقعی |
| W05.06 | سایدبار سمت راست و انیمیشن GSAP جمع‌شدن |
| W05.07 | پشتیبانی `prefers-reduced-motion`، دسترسی کیبورد و منوی موبایل |
| W05.08 | Build و Test روی GitHub Actions با دو base path |

**محدودیت Stage 05:** ورود و دسترسی ادمین تنها نمایشی است؛ ورودی رمز عمداً غیرفعال شده و دکمه‌های پیش‌نمایش هیچ دسترسی مدیریتی واقعی ایجاد نمی‌کنند. ارسال پیام آزمایشی فقط داخل حافظه React است. پروفایل و حساب و API واقعی به مراحل آینده موکول شده‌اند.

## اجرای آزمون‌ها

```bash
cd frontend
npm install
npm run lint
npm run test
VITE_BASE_PATH=/aiapimaker/ npm run build
VITE_BASE_PATH=/ npm run build
```

## آزمون دیداری مورد نیاز پیش از بستن Stage
- 375px: منوی کشویی راست، بدون اسکرول افقی
- 768px: نمایش صحیح پنل‌ها
- 1440px: سایدبار و کارت‌های چندستونه
- کلید Tab، کلیدهای Enter و Escape در منوها، تغییر تم، سایدبار، و Reduced Motion
- بدون نمایش آمار زنده ساختگی یا ادعای ورود موفق

**نشانی نهایی سایت هنوز تعیین نشده است؛ هیچ Nginx یا سرویس عملیاتی تغییر نمی‌کند.**
