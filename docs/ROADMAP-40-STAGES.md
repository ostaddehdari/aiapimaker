# AI API Maker — برنامه اجرایی ۴۰ استیج / ۳۲۰ ورک

**مخزن:** `ostaddehdari/aiapimaker`  
**مسیر استقرار هدف:** `https://srun.ir/aiapimaker/`  
**فناوری‌ها:** React + TypeScript + GSAP + Vazirmatn/Vazir + Font Awesome / Django REST + PostgreSQL + Redis/Celery + Playwright / noVNC + Nginx

## قواعد غیرقابل‌نقض

- حفظ کامل `srun.ir/aigetway/`، Codex CLI، DeepSeek Harness و Antigravity موجود تا پایان مهاجرت و تأیید بازگشت.
- Django مالک تمام APIهای جدید است؛ Flask قبلی تا زمان مهاجرت تأییدشده فعال می‌ماند.
- یک حساب Plus/Pro معادل API رسمی عمومی نیست؛ مجوز، سهمیه و شروط استفاده هر سرویس رعایت شود.
- Browser Agent برای سایت‌های فاقد مجوز خودکارسازی به‌صورت دستی/غیرفعال می‌ماند. هیچ دورزدن CAPTCHA/MFA/rate-limit انجام نشود.
- صدها درخواست می‌توانند در صف ثبت شوند؛ اجرای هم‌زمان تابع منابع CPU/RAM و مجوز ارائه‌دهنده است.
- هر Account/Session/Artifact/API Token به کاربر مالک ایزوله شود؛ هیچ credential در GitHub ثبت نشود.
- هر Stage شامل ۸ Work دقیق، تست، معیار پذیرش و شواهد اجرایی است. قبل از تکمیل stage، stage بعدی تنها در branch آزمایشی شروع شود.
